# Git 规范

## Commit Message 格式
```
<type>(<scope>): <subject>

<body>

<footer>
```

## Type 类型
- `feat`: 新功能
- `fix`: 修复 bug
- `docs`: 文档更新
- `style`: 代码格式调整（不影响逻辑）
- `refactor`: 重构
- `test`: 添加测试
- `chore`: 构建/工具/依赖更新

## 分支管理
- `main`: 生产分支
- `develop`: 开发分支
- `feature/*`: 功能分支
- `fix/*`: 修复分支
- `release/*`: 发布分支
