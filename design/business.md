# 业务规则

> 本文档定义诗歌后端服务的业务规则、核心流程、边界情况和错误处理策略。

---

## 1. 核心概念

### 1.1 实体关系

```
作者 (Author) ←──→ 诗歌 (Poem) ←──→ 分类 (Category)
                              ←──→ 标签 (Tag)
                              ←──→ 收藏 (Favorite)
                              ←──→ 阅读计划 (ReadingPlan)
                              ←──→ 打卡 (Checkin)
                              ←──→ 分享计划 (SharedPlan)
```

### 1.2 角色定义

| 角色 | 说明 | 权限范围 |
|------|------|----------|
| `admin` | 管理员 | 管理后台全部功能 |
| `user` | 普通用户 | 用户端功能（收藏、计划、打卡） |
| `public` | 未认证用户 | 登录、注册、公开内容 |

---

## 2. 诗歌管理

### 2.1 状态机

```
                    ┌──────────────┐
                    │              │
        ┌───────────▼──────────┐   │
        │       draft          │───┘
        │      (草稿)          │ 编辑
        └───────────┬──────────┘
                    │ 发布
        ┌───────────▼──────────┐
        │     published        │
        │      (已发布)         │
        └───────────┬──────────┘
                    │ 归档
        ┌───────────▼──────────┐
        │      archived        │
        │      (已归档)         │
        └──────────────────────┘
```

**状态转换规则**：
- `draft` → `published`：管理员发布
- `published` → `archived`：管理员归档
- `draft` → `published` → `archived`：不可逆

### 2.2 业务规则

| 规则 | 说明 |
|------|------|
| 标题+作者+正文首句唯一 | 导入时自动去重 |
| 默认状态为 draft | 创建时未指定状态自动设为草稿 |
| 拼音可手动校正 | 自动生成后，admin 可编辑覆盖 |
| 简繁体双向转换 | 填一端自动生成另一端，都填以用户输入为准 |
| 作者不参与拼音 | 拼音仅针对标题和正文 |

### 2.3 边界情况

| 场景 | 处理 |
|------|------|
| 标题为空 | 返回 400，"title 不能为空" |
| 作者为空 | 返回 400，"author 不能为空" |
| 正文为空 | 返回 400，"content 不能为空" |
| 重复导入 | 跳过，在响应中标记为 "重复跳过" |
| 批量导入部分失败 | 返回成功/失败明细，不中断整体流程 |
| 拼音生成失败 | 不影响创建，后续可通过工具批量补全 |
| 简繁转换失败 | 不影响创建，原文保留 |

## 3. 拼音与简繁体

### 3.1 拼音生成规则

| 字段 | 是否生成 | 说明 |
|------|----------|------|
| `title_pinyin` | ✅ | 标题拼音（带声调） |
| `content_pinyin` | ✅ | 正文拼音（带声调，保留换行） |
| `author_pinyin` | ❌ | 作者不参与拼音 |

**多音字处理**：
- 自动生成使用默认读音
- admin 可在管理后台手动校正
- 拼音字段独立存储，不覆盖

### 3.2 简繁体转换规则

| 字段 | 是否转换 | 说明 |
|------|----------|------|
| `title_sc` | ✅ | 标题简体 |
| `author_sc` | ✅ | 作者简体 |
| `content_sc` | ✅ | 正文简体 |
| `translation_sc` | ✅ | 译文简体 |
| `appreciation_sc` | ✅ | 赏析简体 |

**转换优先级**：
1. 用户同时提供繁体和简体 → 以用户输入为准
2. 仅提供繁体 → 自动生成简体
3. 仅提供简体 → 保留原样（不反向生成繁体）

## 4. 批量工具

### 4.1 批量生成拼音

```
POST /api/admin/tools/generate-pinyin
```

- 扫描 `title_pinyin` 为空的记录
- 自动生成拼音并更新
- 返回处理数量

### 4.2 批量生成简体

```
POST /api/admin/tools/convert-simplified
```

- 扫描简体字段为空的记录
- 从繁体自动生成简体
- 返回处理数量

### 4.3 提取作者

```
POST /api/admin/tools/generate-authors
```

- 扫描 poems 表的 author 字段
- 去重后插入 authors 表
- 跳过已存在的作者

## 5. 收藏管理

### 5.1 业务规则

| 规则 | 说明 |
|------|------|
| 同一诗歌不可重复收藏 | 重复调用返回成功（幂等） |
| 收藏不存在的诗歌 | 返回 404 |
| 取消不存在的收藏 | 返回成功（幂等） |

### 5.2 边界情况

| 场景 | 处理 |
|------|------|
| 诗歌已被删除 | 收藏记录保留，显示时标记"已下架" |
| 用户删除账号 | 级联删除所有收藏 |

## 6. 阅读计划

### 6.1 状态机

```
┌──────────┐     ┌──────────┐     ┌──────────┐
│  active  │────▶│ paused   │────▶│  active  │
│ (进行中) │◀────│ (已暂停) │     └────┬─────┘
└────┬─────┘     └──────────┘          │
     │                                  │
     └──────────────▶ completed ◀───────┘
                     (已完成)
```

### 6.2 业务规则

| 规则 | 说明 |
|------|------|
| 每日阅读量 | 1-50 篇 |
| 计划天数 | 7/14/30/90 天 |
| 同时只能有一个活跃计划 | 创建新计划需先完成或取消当前计划 |
| 完成条件 | 连续打卡达到计划天数 |

---

## 7. 打卡系统

### 7.1 业务规则

| 规则 | 说明 |
|------|------|
| 每日只能打卡一次 | 重复打卡返回成功（幂等） |
| 打卡需关联阅读计划 | 无活跃计划不可打卡 |
| 连续打卡中断 | 连续天数归零，计划进度保留 |

### 7.2 边界情况

| 场景 | 处理 |
|------|------|
| 跨天打卡 | 以服务器时间为准 |
| 计划已过期 | 不可打卡，需创建新计划 |
| 补卡 | 不支持补卡 |

## 8. 错误处理策略

### 8.1 错误响应结构

```json
{
  "code": 400,
  "message": "请求参数错误",
  "error": "title 不能为空",
  "error_code": "ERR_PARAM_REQUIRED",
  "detail": {
    "field": "title",
    "reason": "required"
  }
}
```

### 8.2 HTTP 状态码映射

| HTTP 状态码 | 场景 |
|-------------|------|
| 400 | 参数缺失、格式错误、JSON 解析失败 |
| 401 | Token 缺失/过期/无效 |
| 403 | 无权访问、非管理员 |
| 404 | 数据库查不到数据 |
| 409 | 业务冲突、状态不匹配 |
| 422 | 验证失败 |
| 500 | 数据库操作失败、未预期错误 |

### 8.3 核心规则

- **数据库查不到数据 → 必须返回 404**，不能返回 400
- **数据库操作失败 → 必须返回 500**，附带具体错误信息
- **参数错误 → 必须标识具体字段名和原因**，不能笼统返回"参数错误"

### 8.4 错误码体系

| 分类 | 范围 | 说明 |
|------|------|------|
| 参数错误 | 1xxx | 缺失、格式错误、超出范围 |
| 认证授权 | 2xxx | 未认证、Token 无效、无权限 |
| 资源不存在 | 3xxx | 用户/诗歌/作者不存在 |
| 业务冲突 | 4xxx | 重复数据、状态不匹配 |
| 服务器错误 | 9xxx | 数据库、内部错误 |

### 8.5 便捷构造函数

```go
errorcode.ParamRequired("title")          // 必填参数缺失
errorcode.ParamInvalid("email", "格式错误") // 参数格式错误
errorcode.Unauthorized()                  // 未认证
errorcode.Forbidden("无权访问")            // 无权限
errorcode.PoemNotFound(id)                // 诗歌不存在
errorcode.DatabaseError("查询诗歌", err)    // 数据库错误
errorcode.Internal("生成令牌", err)        // 内部错误
```

### 8.6 各层错误处理模板

**Handler 层**：
```go
func (h *PoemHandler) GetByID(c fuego.ContextNoBody) (map[string]any, error) {
    id, err := strconv.ParseInt(c.PathParam("id"), 10, 64)
    if err != nil {
        return nil, fuego.BadRequestError{Title: "invalid id", Detail: "无效的诗歌 ID"}
    }

    result, err := h.poemService.GetByID(c.Context(), id)
    if err != nil {
        return nil, fuego.NotFoundError{Title: "not found", Detail: err.Error()}
    }

    return response.Success(result), nil
}
```

**Service 层**：
```go
func (s *PoemService) GetByID(ctx context.Context, id int64) (*model.Poem, error) {
    poem, err := s.poemRepo.GetByID(ctx, id)
    if err != nil {
        if errors.Is(err, pgx.ErrNoRows) {
            return nil, fuego.NotFoundError{
                Title: "poem not found",
                Detail: fmt.Sprintf("诗歌不存在: id=%d", id),
            }
        }
        return nil, fuego.InternalServerError{
            Title: "database error",
            Detail: fmt.Sprintf("查询诗歌失败: id=%d, error=%v", id, err),
        }
    }
    return poem, nil
}
```

## 9. 边界情况汇总

| 场景 | 处理策略 |
|------|----------|
| 并发创建相同诗歌 | 数据库唯一约束，返回 409 |
| 批量导入部分失败 | 返回成功/失败明细，不中断 |
| 拼音生成失败 | 不影响创建，后续批量补全 |
| 简繁转换失败 | 不影响创建，原文保留 |
| 用户删除账号 | 级联删除关联数据 |
| 诗歌被删除 | 收藏/计划保留，标记"已下架" |
| Token 过期 | 返回 401，客户端跳转登录 |
| 无权限访问 | 返回 403，说明所需权限 |
| 分页参数非法 | 使用默认值（page=1, per_page=10） |
| 搜索关键词为空 | 返回 400，"搜索关键词不能为空" |
