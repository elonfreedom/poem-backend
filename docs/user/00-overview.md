# 用户端产品概述

## 产品定位

诗歌应用的用户端（C端），为古诗词爱好者提供浏览、收藏、阅读计划和打卡等功能，帮助用户养成每日读诗的习惯。

## 目标用户

诗歌应用的核心用户是热爱古典诗词的读者群体，他们希望通过每日阅读来感受传统文化的魅力，并借助打卡和计划功能培养持续学习的习惯。

## 用户画像

| 画像 | 描述 | 核心需求 |
|-----|------|---------|
| 诗词爱好者 | 热爱古诗词，每日阅读 | 优质内容、赏析解读 |
| 学生群体 | 学习需要，积累知识 | 分类检索、翻译注释 |
| 习惯养成者 | 希望培养阅读习惯 | 打卡激励、阅读计划 |

## 核心价值

- **优质内容**：精选古诗词，配翻译与赏析
- **习惯养成**：每日推荐 + 阅读计划 + 打卡激励
- **个性化体验**：收藏、阅读记录、连续打卡

## 功能架构

```
用户端
├── 用户系统
│   ├── Passkey 注册登录（通行密钥，一键生物识别）
│   ├── 邮箱恢复（换设备找回账号）
│   └── 个人中心
├── 诗歌浏览
│   ├── 首页（Banner/公告/每日推荐）
│   ├── 诗歌列表（分类筛选）
│   ├── 诗歌详情
│   └── 搜索
├── 收藏
│   ├── 收藏/取消收藏
│   └── 收藏列表
├── 阅读计划
│   ├── 创建计划
│   ├── 记录阅读
│   └── 查看进度
└── 打卡系统
    ├── 每日打卡
    ├── 打卡日历
    ├── 打卡统计
    └── 排行榜
```

## ID 设计

| 实体 | 主键类型 | 说明 |
|-----|---------|------|
| 用户 | UUID v7 | 全局唯一，暴露于 API/JWT |
| 诗歌 | 自增 bigint | 全局共享，无需隐藏 |
| 分类 | 自增 bigint | 内部使用 |
| 标签 | 自增 bigint | 内部使用 |
| 阅读计划 | (user_id, plan_id) | 用户级自增，支持未来分享 |
| 收藏 | (user_id, poem_id) | 复合主键 |
| 打卡 | (user_id, date) | 复合主键 |
| 阅读进度 | (user_id, date) | 复合主键 |
| Passkey | credential_id | 凭证 ID 唯一 |
