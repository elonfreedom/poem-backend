# 非功能需求

## 性能要求

| 指标 | 目标值 | 说明 |
|-----|--------|------|
| API 响应时间 | < 200ms | 95th percentile |
| 并发用户数 | 1000 | 同时在线 |
| 数据库连接池 | 50 | 最大连接数 |
| 文件上传 | < 3s | 图片上传（< 2MB） |

**优化措施**：
- 数据库查询优化，避免 N+1
- 合理使用索引
- 热点数据缓存（如每日推荐、排行榜）
- 分页查询，避免全表扫描

## 安全要求

| 要求 | 说明 |
|-----|------|
| 认证 | JWT Token，有效期 72 小时 |
| 授权 | 基于角色的访问控制（RBAC） |
| 输入校验 | 所有参数服务端校验 |
| SQL 安全 | 参数化查询，防止注入 |
| XSS 防护 | 输出转义 |
| CORS | 生产环境白名单配置 |
| 敏感数据 | 手机号加密存储 |
| 接口限流 | 验证码接口 60s 限制 |

## 可用性要求

| 要求 | 说明 |
|-----|------|
| 接口幂等性 | 打卡、收藏等操作支持重复调用 |
| 优雅降级 | 第三方服务（微信/Apple/短信）不可用时友好提示 |
| 错误提示 | 中文错误信息，便于用户理解 |
| 数据一致性 | 关键操作使用事务 |

## 可观测性

| 要求 | 说明 |
|-----|------|
| 日志 | 请求日志、错误日志、慢查询日志 |
| 监控 | 接口响应时间、错误率、QPS |
| 告警 | 错误率超阈值告警 |

## 部署要求

| 要求 | 说明 |
|-----|------|
| 环境 | 支持 debug / release 模式 |
| 配置 | 环境变量配置，无硬编码 |
| 健康检查 | 提供 /health 端点 |
| 优雅关闭 | 处理完当前请求后退出 |
