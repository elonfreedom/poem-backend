# 后台管理产品概述

## 产品定位

诗歌应用的后台管理系统（Admin），为内容运营人员提供诗歌内容管理、数据统计和系统配置功能。

## 目标用户

- **管理员**：负责诗歌内容管理、用户管理、系统配置
- **运营人员**：查看数据统计分析

## 角色权限

| 角色 | 权限 |
|-----|------|
| admin | 所有功能 + 后台管理 |
| user | 仅用户端功能（无后台权限） |

## 功能架构

```
后台管理
├── 诗歌管理
│   ├── 诗歌 CRUD
│   ├── 状态管理（草稿/发布/归档）
│   ├── 分类管理
│   └── 标签管理
├── 数据统计
│   ├── 总览数据
│   ├── 每日统计
│   ├── 热门诗歌
│   └── 用户增长
└── 系统配置
    ├── Banner 管理
    ├── 公告管理
    └── 系统参数配置
```
